# F5L COLLECTOR
This project is related to model aircrafts - Aeromodelling, specifically to F5L RC Electric gliders competitions.

An offline-capable app for recording contest flight data and exporting it in GliderScore-compatible CSV format. It is not intended as a replacement for the original GliderScore app, but an alternative able to work offline with a simple high-contrast design for better visibility in phones and tablets used under direct sunlight.

## Installation and usage
* Get the app by pointing your browser to https://f5lcollector.up.railway.app.
* Your device will enable an installation link (the app is PWA capable) to use it offline.
* Input the data during the contest, it will be saved on a local device database.
* Once finished, use the button to export it to a CSV file (GliderScore compliant).
* Import the CSV file into GliderScore to retrieve the contest data and generate the final results.
